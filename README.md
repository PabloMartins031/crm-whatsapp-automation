# CRM WhatsApp Automation

Sistema de CRM e automação para WhatsApp desenvolvido com Node.js e WhatsApp Web JS. O projeto tem como objetivo centralizar o atendimento de clientes, automatizar respostas, registrar histórico de conversas e servir como base para soluções de vendas, suporte e relacionamento.

## 🚀 Funcionalidades

* Integração com WhatsApp Web
* Autenticação persistente com LocalAuth
* Menu de atendimento automatizado
* Fluxo de navegação por opções
* Gerenciamento de estados do usuário
* Histórico de mensagens
* Integração com banco de dados
* Estrutura preparada para CRM

## 🛠️ Tecnologias Utilizadas

* Node.js
* JavaScript
* WhatsApp Web JS
* Puppeteer
* MySQL
* Git e GitHub

## ⚙️ Instalação

Clone o repositório:

```bash
git clone https://github.com/PabloMartins031/crm-whatsapp-automation.git
```

Acesse a pasta:

```bash
cd crm-whatsapp-automation
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
node bot.js
```
